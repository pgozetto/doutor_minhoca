# Doutor Minhoca

Site institucional e catálogo digital do Doutor Minhoca, criado para apresentar húmus, matrizes de minhocas, formas de envio e atendimento via WhatsApp.

## Destaques

- Direção visual botânica premium, em tons profundos de verde.
- Catálogo interativo com três opções de húmus e quatro espécies de minhocas.
- Detalhes expansíveis com preços ilustrativos, usos recomendados e botões de encomenda pelo WhatsApp.
- Efeitos de parallax, onda ao passar o mouse na imagem principal e texto com efeito de digitação.
- Layout responsivo e respeito à preferência de redução de movimento do dispositivo.

## Tecnologias

- Next.js
- React
- TypeScript
- CSS modularizado por camadas visuais

## Como executar localmente

```bash
npm install
npm run dev
```

Depois, abra o endereço exibido no terminal.

## Gerar a versão de produção

```bash
npm run build
```

O projeto está configurado para gerar uma versão estática na pasta `out`, pronta para hospedagem.

## Observação

Os valores mostrados nos produtos são ilustrativos, para fins de apresentação inicial do site. Eles podem ser atualizados no conteúdo da página conforme a tabela comercial definitiva.
